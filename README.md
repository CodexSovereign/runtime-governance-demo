# Signal → Slow → Pause → Refuse

A Python state machine demo implementing runtime governance rails:

- **Signal** — detect and ledger awareness  
- **Slow** — throttle throughput while custody checks apply  
- **Pause** — hold execution until custody is confirmed  
- **Refuse** — halt execution if legitimacy fails  

Each transition is immutably recorded in a ledger with timestamps, showing how custody enforcement can be structural rather than statistical.

---

## Purpose
This project is a **conceptual demonstration** of runtime governance. It illustrates programming style, clarity, and documentation practices — not production code.
